# Guia de leitura

Um documento Markdown pode reunir **ideias importantes**, *anotações* e `trechos de código` em um só lugar.

## Organize suas anotações

- Separe os assuntos com títulos.
- Use listas para acompanhar as próximas tarefas.
- Inclua links, tabelas e exemplos quando precisar.

> Uma boa documentação começa com informações fáceis de encontrar.

## Acompanhe o progresso

| Etapa | Situação |
| --- | --- |
| Abrir o documento | Concluída |
| Ler a visualização | Em andamento |
| Revisar as anotações | Pendente |

## Exemplo de código

```csharp
var mensagem = "Olá, Markdown!";
Console.WriteLine(mensagem);
```
